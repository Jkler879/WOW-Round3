核心发现 — Faithfulness 实现本轮最大提升 +0.1242（相对 +25.3%），从 0.490 升至 0.614；Reasoning 题 F 从 0.351 升至 0.495，幻觉率显著下降。同题集、同 ground_truth（Sonnet 生成），三方独立模型参与（Sonnet 出题 / qwen3-30b 答题 / qwen-plus 评判），严格 A/B 对比，185 条题目与参考答案完全一致。
循环偏差（Circular Bias） — Context Precision（0.950）和 Context Recall（0.937）因评估集为 KB 派生题而结构性虚高；两轮均采用相同评估集，轮次间相对比较有效，但绝对值不可对外引用。Faithfulness 和 Answer Correctness 受循环偏差影响最小，是本轮最具诊断价值的指标。 AR=0 artifact（11.5%）为 RAGAS 英文硬编码 prompt 多语言问题，全程使用 AR(非零) 口径以保持两轮可比性。
